# CityEvents

A full-stack web application for discovering,
creating and managing events in your city.

## Tech Stack

### Backend
- Java 25
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven

### Frontend
- Angular
- TypeScript
- RxJS

### Database
- PostgreSQL
- Flyway

### Infrastructure
- Docker
- Docker Compose

## Project Structure

```text
city-events/
├── backend/
├── frontend/
├── docker/
├── docs/
├── compose.yaml
├── .env.example
└── README.md
```
